# Folk Village

같은 마을에 접속한 사람들과 채팅하고, 가상 휴대폰으로 친구를 맺고 문자를 주고받는 2D 픽셀 소셜 네트워크 게임.

| 장르 | 인원 | 기간 | 엔진 |
|---|---|---|---|
| 2D 소셜 네트워크 게임 | 1인 | 2023.09 — 12 | Unity 2022.3 |

---
## 주요 기능

### 멀티플레이
- **채널 입장** — 룸이 없으면 만들고 있으면 들어가는 방식으로 마을 하나에 최대 10명

- **위치 · 애니메이션 동기화** — 이동과 애니메이션은 Photon의 동기화 컴포넌트가 담당

- **좌우반전 동기화** — 걷기 애니메이션은 한 방향만 두고 반전 상태를 원격 호출로 공유

- **말풍선 채팅** — 머리 위 말풍선이 일정 시간 뒤 닫히고, 거리가 멀어지면 보이지 않음

- **전체 채팅과 일반 채팅** — 같은 입력창에서 대상을 바꿔 보냄

- **음성 채팅** — 캐릭터가 생성되는 순간부터 같은 룸 접속자와 대화

- **욕설 필터** — 전송 직전 사전과 대조해 걸러냄

### 가상 휴대폰
- **회원가입 · 로그인** — 계정을 서버에 저장하고, 로그인 시 받은 닉네임을 그대로 게임 표시 이름으로 사용

- **친구** — 검색 · 신청 · 알림 · 수락 · 목록

- **문자** — 대화방 목록, 전송, 안읽음 표시, 대화창을 연 동안 새 문자 수신

- **선물** — 하트를 보내고, 받은 쪽이 수락하면 코인이 증가

### 마을 생활
- **상점** — 가구 · 벽지 · 바닥 구매, 코인 차감

- **집 꾸미기** — 보유 아이템을 드래그해 배치하고 위치를 저장

- **아바타 꾸미기** — 머리 · 얼굴 · 상의 · 하의를 부위별로 교체

## 조작법

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` · `방향키` | 이동 |
| `LeftShift` | 달리기 |
| `Enter` | 채팅 전송 |
| `마우스` | 휴대폰 · 상점 · 꾸미기 UI 조작 |

> [!NOTE]
> 채팅 입력창에 포커스가 있는 동안에는 이동 입력을 받지 않습니다. 채팅 중 캐릭터가 움직이는 것을 막기 위한 처리입니다.

## 프로젝트 구조

```
Unity/Assets/Scripts/
├─ NetworkManager              룸 생성 · 입장 · 참여자 목록
├─ PlayerMove                  이동 · 좌우반전 · 말풍선
├─ ChatManager                 전체 · 일반 채팅 · 전송 대상 분기
├─ BadWord/                    욕설 사전 로드 · 문장 검사
├─ JoinScript/                 회원가입 · 로그인
├─ PhoneScript/
│  ├─ Friend/                  검색 · 신청 · 알림 · 수락 · 목록
│  ├─ Message/                 대화방 · 전송 · 읽음 처리 · 하트
│  ├─ Gift/                    선물 수락 · 코인 반영
│  └─ Call/                    통화 목록
├─ Store/                      상점 목록 · 구매 · 보유 갱신
├─ House/                      집 인벤토리 · 드래그 배치
├─ CharacterCustom/            부위별 아바타 교체
└─ CoinSetting                 코인 조회 · 갱신

PHP/
├─ userInfo/                   계정 · 코인 · 선물 수령
├─ phoneFriend/                친구 관련
├─ phoneMessage/               문자 관련
└─ heart/                      하트 선물
```

씬은 로그인, 회원가입, 닉네임 설정, 마을, 상점, 집, 아바타 꾸미기로 나뉩니다.
